# PDF Studio

Личная PDF-мастерская с русским интерфейсом и светлой и тёмной темами. Документы обрабатываются в браузере. Сервер раздаёт файлы приложения и модели распознавания.

## Локальный запуск

Требуется Node.js 22 или новее. В папке проекта выполните:

```powershell
npm.cmd start
```

Откройте http://127.0.0.1:4173. Если порт занят, задайте переменную окружения `PDF_STUDIO_PORT`.

В `dist/` находится готовая статическая версия. Чтобы заново собрать сторонние компоненты:

```powershell
npm.cmd ci
npm.cmd run prepare-assets
```

## Особенности работы с файлами

- Редактор добавляет слои поверх существующих страниц. Подпись в редакторе представляет собой графический штрих.
- Сжатие с потерями и скрытие областей создают PDF из изображений страниц. Сжатие без потерь пересохраняет структуру PDF.
- DOCX → PDF сохраняет оформление предпросмотра; PDF → Word переносит извлечённый текст. Доступные языки OCR — русский и английский.
- Защита использует пароль для открытия с 256-битным шифрованием. При снятии защиты укажите действующий пароль.

## Визуальное управление страницами

После загрузки PDF появляются миниатюры. Нажмите миниатюру для крупного просмотра. Корзина удаляет страницу; стрелки меняют порядок, ↻ поворачивает, ⧉ дублирует. Есть групповой выбор, поворот, удаление и отмена изменений страниц. В извлечении галочки задают страницы результата, в разделении кнопки разреза задают части.

Все инструменты принимают несколько файлов. Кнопка «Открыть» переключает активный документ; обработка сохраняет открытый файл. Объединение PDF и сборка изображений используют всю очередь. Правки страниц сохраняются при переключении между файлами в одном инструменте.

## Рабочее пространство

Полноэкранный рабочий экран: документ в центре, очередь файлов и настройки сбоку. Переключатель инструментов сохраняет изменения страниц и аннотации, вкладки «Документ» и «Все страницы» меняют режим просмотра. После обработки PDF можно продолжить редактирование результата. На узком экране панель настроек сворачивается кнопкой.

## Цвет и экспорт изображений

Инструмент «Цвет и контраст PDF» меняет яркость, контрастность, насыщенность, теплоту и резкость выбранных страниц. Доступны серый, чёрно-белый, сепия и инверсия. Предпросмотр обновляется при настройке. Обработанные страницы становятся изображениями и теряют текстовый слой; остальные страницы копируются из исходника.

JPG и PNG экспортируются с разрешением до 600 dpi, с записью плотности в метаданные изображения. A4 при 600 dpi — примерно 4961 × 7016 пикселей. Настройки цвета и резкости доступны и при экспорте; для JPG можно задать качество. Страницы обрабатываются последовательно. Слишком большие растровые страницы отклоняются с предложением снизить dpi, без скрытого уменьшения разрешения. Повышение dpi не восстанавливает отсутствующие детали исходного скана.

## Производительность

Миниатюры показываются блоками по 48 страниц; в фоне одновременно отрисовываются не более двух. Кэш миниатюр ограничен, изображения освобождаются при закрытии документа. Выбор галочек не перестраивает список страниц. Предпросмотр хранит две исходные отрисовки и повторно использует их при цветокоррекции; устаревшие запросы пропускаются.

Редактор и миниатюры используют общий PDF-документ и один PDF.js worker. Неактивные редакторы освобождают холсты и очищают декодированные данные, сохраняя правки. Объединение, разделение, перестановка страниц и цветокоррекция выполняются в фоновых workers. При объединении файлы читаются последовательно внутри worker. Разделение разбирает исходный PDF один раз. Неизменённые документы не пересобираются.

Компоненты Word, дополнительных шрифтов и ZIP загружаются по необходимости. Рисование обновляется не чаще одного раза за кадр. 600 dpi сохраняются без снижения разрешения; длительность экспорта зависит от размера документа и устройства.

## Размер страниц PDF

Инструмент «Размер страниц PDF» меняет выбранные страницы на A0–A6, B4/B5, Letter, Legal, Tabloid или размер в миллиметрах. Можно задать книжную, альбомную или исходную ориентацию и поля. Режимы: вписать целиком, только уменьшать, заполнить лист с обрезкой или разместить по центру без масштабирования. Предпросмотр обновляется при настройке. Обработка выполняется в worker без растрирования: сохраняются текст, векторная графика, поля формы и метаданные.

## Предпросмотр исходников и оформление Word

В инструментах конвертации доступны предпросмотры всех поддерживаемых исходников: JPG/JPEG, PNG, WebP, DOCX, TXT, CSV, Markdown и HTML. DOCX отображается со стилями текста, таблицами, изображениями, колонтитулами, встроенными шрифтами и разрывами страниц. CSV показывается таблицей, Markdown — с разметкой, HTML — с локальным оформлением в изолированном документе. Внешние изображения и стили не загружаются.

DOCX, HTML, Markdown и CSV конвертируются из оформленного предпросмотра в изображения страниц PDF (96–300 dpi); прежнее извлечение обычного текста для DOCX больше не используется. Это сохраняет визуальное оформление, но прямое скачивание не содержит выделяемого текстового слоя. Кнопка «Печать / PDF с текстом» открывает системное окно печати для сохранения документа браузером. TXT по-прежнему экспортируется с текстовым слоем. Сложная вёрстка и отсутствующие шрифты могут отличаться от Microsoft Word; точность зависит от браузерной отрисовки. Компоненты предпросмотра загружаются только при необходимости.
