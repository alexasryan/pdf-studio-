Перед началом работы

Куда попадают мои файлы?

Обработка выполняется в вашем браузере. Документы не отправляются на сервер обработки. Список «Недавно открывали» хранит только названия инструментов — без имён и содержимого файлов.

Как сохранить результат?

Добавьте документ, выберите настройки и нажмите кнопку сохранения в редакторе. После обработки появится ссылка «Скачать». Исходный файл на вашем устройстве не перезаписывается.

Сохранится ли оформление?

Это зависит от инструмента. DOCX → PDF сохраняет оформление предпросмотра как изображения страниц; для PDF с выделяемым текстом есть кнопка печати. Сложная вёрстка и отсутствующие шрифты могут отличаться от Word. PDF → Word переносит текст без исходной вёрстки. Сжатие с потерями превращает страницы в изображения. Особенности каждого действия описаны в настройках инструмента.
